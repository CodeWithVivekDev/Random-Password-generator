# Random Password Generator

A simple and intuitive web application for generating random passwords with one click.

## Features

- **One-Click Generation**: Generate secure random passwords instantly
- **Copy to Clipboard**: Easily copy the generated password with a single click
- **Diverse Character Set**: Includes uppercase, lowercase, numbers, and special characters
- **Responsive Design**: Works seamlessly on desktop and mobile devices
- **Visual Feedback**: Get instant feedback when a password is copied

## Demo

1. Click the **Generate** button to create a new random password
2. The password appears in the input field
3. Click the copy icon to copy the password to your clipboard
4. A notification confirms the password has been copied

## Technical Stack

- **HTML5**: Markup and structure
- **CSS3**: Styling and responsive design
- **JavaScript**: Dynamic functionality and password generation logic

## Password Specifications

- **Length**: 14 characters
- **Character Types**: 
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*()_+?:{}[])

## How to Use

1. Open `index.html` in your web browser
2. Click the **Generate** button to create a password
3. Click the copy icon to copy the password to clipboard
4. The alert message will confirm the copy action
